Scaffold a new component in this project. Ask the user which type:

- **Agent**: Follow `.agents/skills/add-new-agent.md`
- **API endpoint**: Follow `.agents/skills/add-api-endpoint.md`

After scaffolding:
1. Add all required type annotations
2. Create corresponding test file in `tests/`
3. Export new symbols in `__init__.py` files
4. Run `mise run v` to verify
